# Guitar Lab

一个逐步成长的吉他练习项目。第一步，从「和弦 ↔ 指板」开始：理解和弦需要哪些音，找到它们在吉他上的位置，再从一组按法反查和弦。

## 本地运行

使用 Python 3.10 或更新版本：

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

打开终端显示的本地地址。基础功能在本地计算，不需要 API key 或 AI 服务。

## 第二版

- **和弦音位置**：输入 `C`、`Am`、`G7`、`Bbmaj7` 等，显示构成音、相对根音的半音距离，以及指板上的对应位置。
- **常用按法**：标出当前品位范围内的全部和弦音，并用深色描边突出 C、G、D、A、E、Am、Em、Dm、F 的一组预设按法。未收录按法的和弦仍显示全部构成音位置。
- **反向识别**：直接点击指板选音，同弦换位替换，再次点击取消。支持清空和 C / Am 示例；显示每个候选的构成音、音程名称、半音公式和实际最低音。未匹配时显示各个根音假设下的半音集合。

标准调弦按 6 弦到 1 弦为 E2 A2 D3 G3 B3 E4。图中上方是 1 弦，0 品表示空弦，X 表示不弹。红色表示已知和弦的根音，黄色表示其他选中音。

例如 C 大三和弦由 C、E、G 组成，相对根音为 0、4、7 个半音；常用按法为 `X 3 2 0 1 0`（6 弦 → 1 弦）。在反向识别中选择这组按法可以得到 C，并看到根音、大三度、纯五度的推导。缩小显示范围不会删除范围外的选音，界面会提示；可扩大范围编辑或清空。

**指板上的全部和弦音是可选位置，不是一组需要同时按下的指法。** 同一组音也可能有多个名称，例如 C6 与 Am7；应结合最低音和音乐上下文理解。

## 范围与限制

支持大/小三和弦、dim、aug、sus2、sus4、7、maj7、m7、6、m6、m7b5、dim7 及下述扩展和弦，支持升降号音名。构成音按音程度数拼写，例如 C# 大三和弦为 C#、E#、G#；悬停音名采用统一的升号写法。

反向识别忽略八度重复，按完整音级集合匹配，并根据实际最低音显示转位名称（例如 C/E）。未匹配只表示当前模板库无法完整匹配，不代表这些音不能构成和弦。可选省略音匹配见下文；暂不支持忽略额外音、斜杠和弦输入、自定义调弦或自动生成可弹指法。

## 项目结构

```text
core.py          纯 Python 乐理计算，不依赖界面或模型
app.py           Streamlit 交互与 Plotly 指板
coach.py         可选的 AI 教练实验入口
tests/           乐理与界面回归测试
```

后续功能优先复用 `core.py`，保持计算、界面和 AI 解释分离。和弦类型扩展入口为 `CHORD_FORMULAS`，常用按法扩展入口为 `KNOWN_SHAPES`。

`coach.py` 是独立实验，不属于基础安装：需要另行安装 `langchain` 和对应模型提供方依赖，设置 `LANGCHAIN_MODEL`（`提供方:模型名`）及提供方凭据。不要将 API key 提交到仓库。

## 反向识别：根音与音程分析

直接在原有「反向识别」页面使用：选音后可指定根音（含升降号）或自动判断，选择候选查看音程分析表。根音不等于最低音，也可以不在实际选音中。

新增 add9、madd9、9、maj9、m9、11、m11、13 公式。扩展音按功能标注，半音差按 12 取余，不要求实际弹在高八度。十三和弦采用含九音、十一音的完整公式，六根弦不能弹全，需开启省略音。

「允许省略音」默认关闭；开启后仅允许省略根音或纯五音，至少需要两个不同音级，保留三音、七音、变化音和扩展音，不忽略额外音。结果区分完整匹配与可能解释，并列明未弹奏的音。候选按完整匹配、省略音数量、根音是否为最低音及公式规模排序，不表示概率。

例如 C、E、G、D 指定根音 C 得到 Cadd9；E、Bb 指定根音 C 并开启省略音，得到 C7/E 的可能解释（缺 C、G）。

## 和弦轨道

侧边栏打开「和弦轨道」，在页面底部选择歌曲主音、调式和拍号。轨道以横向小节排列，连接线串联小节；直接在轨道中的和弦格子输入名称或数字、调整占拍，无需下滑到另一套编辑表单。小节较多时横向滚动，支持添加/删除小节及和弦。

模块输入接受和弦名或数字标记：C 大调的 `Cmaj7` 与 `1maj7`、`Am7` 与 `6m7` 均可输入，提交后自动显示对应名称、数字与构成音。`57` 表示五级根音的七和弦；裸数字表示大三和弦，小和弦需加 `m`。自然小调以主音为 1。升降级数保留音名拼写区别，例如 C 大调的 `b7` 为 Bb，`#4` 为 F#。

改变调性会重新解释数字输入，字母输入则保持原和弦。支持 4/4、3/4、6/8；占拍为整数，前两者以四分音符为单位，6/8 以八分音符为单位，按 3+3 分组。模块宽度按占拍比例展示，空余位置显示为休止/待填，超出容量时明确提示（不自动跨小节）。切换拍号保留原占拍，必要时需手动调整。

目前提供和弦与占拍的可视编排，尚无音频播放或跨会话存储。关闭工具或切换页面保留当前会话数据。

界面位于 `track.py`，调性分析及输入转换位于 `core.chord_in_key`、`core.resolve_track_chord`。


轨道末尾提供「和弦走向 · 数字总览」：每行四小节，圆点仅标数字和弦名，起拍决定横坐标，占拍以水平线段长度表达。纵坐标为统一 C4–B4 范围内的根音音高，不代表实际演奏指法或声部进行。颜色区分大、小、属七、增减五音及挂留结构。空白/无效输入留空，超出拍号容量的小节提示修正后再绘制。
